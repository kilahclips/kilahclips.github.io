Privacy Policy

Kilah Clipping has a single user: its owner. It does not collect personal data from anyone else, and it has no public sign-up.

Data the tool uses

  • YouTube (Google) data: an OAuth access token for the owner's channel with the scopes to upload videos and read basic channel information. It is used only to upload the owner's approved clips and to confirm their settings (privacy, category, made-for-kids status).
  • TikTok data: an OAuth access token and the owner's basic profile information (display name, open ID), used only to upload the owner's approved clips to their own account.
  • Publishing history: date, platform, title and link of each published clip, kept to avoid publishing the same clip twice.

Storage and sharing

All data is stored locally on the owner's computer, with access limited to the owner's user account. It is never sold, shared with third parties, or used for advertising. Google user data is used in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time from the Google account security settings (myaccount.google.com/permissions) and from TikTok (Settings and privacy, Security and permissions, Apps and services). Deleting the tool's local files removes all stored data.
